# 使用手册

## 简历模块
在“职业发展”栏中嵌入了简历模块，模块中用户可以**上传简历**、**创建会话**、**删除会话**，在会话中简历助手的协助下完成自己简历的优化，
帮助学生更好的职业发展。

## 面试模块
（注：由于证书原因，用户还不能直接使用语音输入功能，除非使用Chrome浏览器并添加域名于白名单）
在“职业发展”栏中嵌入了AI面试模块，模块中用户可以连接数字人面试官，身临其境地来一场与AI面试官的模拟面试，帮助学生建立对面试流程、常见专业问题的认知，从而有更加充分的能力与信心去面对真实面试。

要开启一场Ai面试，先点击**新建会话**,然后**连接数字人**,等待连接成功后面试官将会发送开场白信息，面试开始。
